# Ability Icons Round 25

All three source images were generated separately with the built-in image
generation path. The supplied Teeny Titans images were used as concept and
palette references rather than edit targets. Flat chroma-key backgrounds were
removed locally before nearest-neighbor production export.

`deadly_kiss` and `puddin_pucker` intentionally reuse the same approved kiss
symbol source. `macho_smooch` will receive a separate design in a later round.

## Stinky Fish

Create exactly one throwable stinky fish for a production Minecraft Forge mod
ability-item icon, intended for final nearest-neighbor reduction to a 64x64
RGBA sprite and clear recognition at 32x32. Use the supplied Stinky Fish image
only as a concept and palette reference.

Draw a compact dead fish with a pale mint-blue body, dark teal outline, one X
eye, a small jagged mouth/gill mark, purple bruised patches, and exactly three
chunky lime-green stink wisps above it. Center it with the head pointing
upper-left and the tail lower-right at roughly 35–45 degrees. Add exactly
three short motion streaks trailing toward the lower-right.

Use authentic hand-placed Minecraft-style pixel art: a strong silhouette,
hard square clusters, a limited palette, colored shadows, crisp stair-stepped
edges, and no micro-detail. Use a perfectly flat `#ff00ff` chroma background.
No UI button, frame, character, hand, extra fish, text, watermark, glow, blur,
antialiasing, or smooth vector curves.

## Deadly Kiss / Puddin' Pucker

Recreate only the central kiss-symbol design from the supplied reference as a
production Minecraft Forge mod action icon. This is not a mouth and contains
no lips.

Draw exactly one compact coral-red/pink circular outline, a matching diagonal
bar running lower-left to upper-right across it, a flat light-pink circular
interior, and exactly one solid black heart centered inside. Preserve the
reference's proportions and palette relationships. The heart remains
recognizable behind the diagonal bar. Keep the complete symbol deliberately
small and centered with generous padding.

Use authentic chunky Minecraft-style pixel art with consistent line
thickness, hard square clusters, crisp stepped edges, minimal shading, and
readability at 64x64 and 32x32. Use a perfectly flat `#00ff00` chroma
background. No yellow/gold button frame, mouth, lips, teeth, tongue, face,
extra hearts, text, watermark, glow, blur, antialiasing, or smooth curves.

## Darwin

Create exactly one partially open red Theory-of-Evolution-style book being
thrown for a production Minecraft Forge mod throwable ability icon. Use the
supplied book image only as a book-design and palette reference.

Draw one red/magenta hardcover book with a dark red spine, bright red edge
highlights, cream/yellowed pages, and a visible front cover. Open it roughly
25–35 degrees so the red cover remains dominant while a chunky wedge of pages
is visible. Put exactly three short rows of abstract black pixels on the cover
to suggest a title without readable words or letters.

Center it on a 35–45-degree lower-right-to-upper-left throwing diagonal, with
the leading cover corners directed upper-left. Add exactly three short motion
streaks trailing toward the lower-right. Use a strong, limited-palette,
Minecraft-style pixel-art silhouette with hard square clusters and crisp
stepped edges. Use a perfectly flat `#00ff00` chroma background. No UI frame,
character, gorilla, hand, desk, extra books, readable text, watermark, stun
symbol, glow, blur, antialiasing, or smooth vector curves.
